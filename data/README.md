# Data Folders

Use this folder as the default local workspace for client artifacts.

```text
data/
  dataset/
    Brand A/
      Product A/
        image_1.jpg
    __Unknown__/
      unknown/
        negative_1.jpg
  input_images/
    image_to_classify.jpg
  outputs/
    memory_bank_cache/
    threshold_optimization_results/
    inference_results/
```

Do not commit real client images or generated model artifacts unless the repository is intentionally private and versioned for deployment.
